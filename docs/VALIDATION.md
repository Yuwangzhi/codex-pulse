# 0.2.0 验证记录

环境：macOS 26.6 / Apple Silicon，Codex CLI 0.154.0。

- `scripts/swift-tool.sh test`：13 项通过，包含日志解析、额度口径，以及新增任务搜索 / 筛选 / 排序。
- Release 构建与安装包签名校验通过。
