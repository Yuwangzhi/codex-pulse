# Claude 额度恢复验证 · 0.5.9

Claude Code 的账户仍然登录时，短期 Access Token 也会到期。0.5.8 在这个阶段清空额度，并等待 Claude Code 的其他操作续期。0.5.9 主动调用本机官方 CLI 的初始化和用量检查，由 CLI 处理续期；额度监测保持独立于模型路由。

验证环境：macOS、Claude Code 2.1.310、AI Pulse 0.5.9。

| 场景 | 验证方式 | 结果 |
| --- | --- | --- |

| 断网、恢复、重启 | 保存缓存、重建监测器、恢复接口 | 保留原读取时间，新值到达后恢复正常状态 |
| 钥匙串暂时不可读 | 读取失败后恢复 | 保留已确认的旧值，解锁后自动恢复 |
| 换账户、请求期间退出登录 | 请求过程中替换凭据或退出 | 丢弃旧账户响应及缓存 |

| 正式 Swift 恢复实现 | 编译并运行与 App 相同的恢复器、凭据读取及额度服务 | 完成官方检查并取得当前额度 |
| 安装与重启 | 安装、严格签名验证、二进制哈希比对、原生界面检查 | 安装产物一致，Claude 两个窗口正常显示 |
